# Skystore

Интернет-магазин на Django для продажи плагинов и примеров кода.
Проект дорабатывается на каждом уроке курса.

## Возможности

- Главная страница со списком товаров из базы данных и постраничным выводом
- Детальная страница товара с полной информацией
- Страница добавления нового товара через форму
- Страница контактов с формой обратной связи
- Базовый шаблон и подшаблон меню — все страницы наследуют общую разметку
- Модели категорий и продуктов, связанные через ForeignKey
- Админка, фикстуры и кастомная команда для наполнения базы

## Стек

- Python
- Django 5.2
- PostgreSQL
- Bootstrap 5

## Установка

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка базы данных

Создайте базу данных PostgreSQL, затем скопируйте `.env.sample` в `.env`
и укажите свои параметры подключения.

## Запуск

```
python manage.py migrate
python manage.py fill
python manage.py createsuperuser
python manage.py runserver
```

Приложение доступно по адресу http://127.0.0.1:8000/

## Маршруты

- `/` — главная страница (каталог со списком товаров)
- `/products/<int:pk>/` — детальная страница товара
- `/products/create/` — добавление нового товара
- `/contacts/` — страница контактов
- `/admin/` — административная панель
